# Automation_for_business

Automation for business — набор практических скриптов и инструментов для автоматизации бизнес-процессов: финансы, банки, отчётность, уведомления и серверные задачи. Проекты ориентированы на реальное использование и запуск по расписанию.

## Проекты:

* [T-Bank Overnight Automation](https://github.com/Jopel003/Automation_for_business/tree/main/tbank-overnight) — автоматизация ежедневного размещения свободных средств в overnight Т-Банка с уведомлением в Telegram.
