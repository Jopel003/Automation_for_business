# T-Bank Overnight Automation

Автоматизация ежедневного размещения свободных денежных средств в **овернайт Т-Банка** с уведомлением в **Telegram**.

Проект предназначен для запуска на сервере (VPS / dedicated) и может работать по расписанию (cron), автоматически:

* получает текущий баланс расчётного счёта,
* округляет сумму,
* размещает средства в overnight,
* отправляет уведомление о результате в Telegram.

---

## 🚀 Возможности

* Получение баланса по счёту через **T-Bank Business OpenAPI**
* Автоматическое пополнение overnight-соглашения
* Поддержка **mTLS (client certificate)**
* Уведомления в Telegram
* Минимум зависимостей (единственная — `python-dotenv`)
* Подходит для ежедневного автозапуска

---

## 🧠 Как работает логика

1. Скрипт запрашивает список счетов
2. Получает баланс указанного счёта
3. Округляет сумму до тысяч рублей
4. Если сумма ≥ 100 000 ₽ — размещает её в overnight
5. Отправляет сообщение в Telegram:

   * ✅ успех
   * ❌ ошибка

## 🔐 Конфигурация

Все секреты хранятся в файле `.env` (не в `.json`).

Создайте его из шаблона:

```bash
cp .env.example .env
```

И заполните своими значениями:

```env
# --- T-Bank Business OpenAPI ---
TBANK_API_TOKEN=YOUR_TBANK_API_TOKEN
TBANK_ACCOUNT_NUMBER=YOUR_ACCOUNT_NUMBER
OVERNIGHT_AGREEMENT_NUMBER=YOUR_OVERNIGHT_AGREEMENT

# --- mTLS ---
CERTFILE=cert.pem
KEYFILE=key.pem

# --- Telegram-бот ---
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID=YOUR_CHAT_ID
```

Значения подгружаются через `python-dotenv` при запуске скрипта (`load_dotenv()`), при этом уже заданные переменные окружения имеют приоритет над файлом.

⚠️ **Важно:**

* `.env`, `*.pem`, `*.key` **не должны попадать в GitHub**
* `.env` и сертификаты уже добавлены в `.gitignore` (корень репозитория)
* если какой-то переменной нет, скрипт завершится с понятной ошибкой:
  `Переменная XXX не задана — добавьте её в файл .env`

## ▶️ Запуск

Установите зависимость и запустите скрипт:

```bash
pip install python-dotenv
python overnight.py
```

Пример автозапуска через `cron` (удобно использовать на Linux, так как overnight необходимо выставлять **до 17:00**, пример — каждый рабочий день в 16:45):

```bash
45 16 * * 1-5 /usr/bin/python3 /path/to/overnight.py
```

## ⚠️ Ограничения и допущения

* Скрипт рассчитан на **один основной счёт**
* Сумма округляется **в меньшую сторону до 1 000 ₽**
* Минимальная сумма размещения: **100 000 ₽** (требование банка — минимальная сумма для overnight)
* Не реализована повторная попытка при ошибке API
